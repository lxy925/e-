# e陪无忧（e-Care）—— 智能医疗陪诊服务小程序

一款基于 **uni-app + Vue + uniCloud (阿里云 Serverless) + uView UI** 开发的全流程医疗陪诊与就医服务小程序。项目集成了**患者端陪诊预约**、**陪诊师工作台与日程排班**、**AI 智能健康咨询**、**陪诊师在线培训与考证题库**、**微信支付与资金提现结算**等全链路业务能力。

## 1. 项目概述与业务架构

## 2. 核心功能与业务模块

### 2.1 患者与用户服务
1. **陪诊服务预约**：提供基础陪诊、尊享全程陪诊、代办就医、专车接送等不同规格的陪诊服务。
2. **精细化下单配置**：
   - 选择服务医院、科室、就诊时间；
   - 绑定就诊人（支持管理多个就诊人，包含病史、过敏史等）；
   - 接送地址选择（支持地图选点与精准地址）；
   - 上传病历、就诊卡、检查单等就医材料；
   - 就诊人特点偏好（方言需求、轮椅需求、沟通偏好、陪诊师性别/经验偏好等）。
3. **支付与订单管理**：集成微信支付与收银台（uni-pay），支持订单状态流转（待付款、待服务、服务中、已完成、已取消）及退款申请。
4. **AI 智能问诊助手**：集成百度文心一言（ERNIE-Bot）大模型，支持上下文问答与历史会话管理，为用户提供就医指引与健康咨询。
5. **健康百科与便民指南**：提供急救指南、重疾预防科普、医院官网直通车（WebView 嵌套）。

### 2.2 陪诊师工作台
1. **资质入驻与认证**：陪诊师身份登记、从业资质认证、个人介绍与技能标签展示。
2. **日程与排班管理**：可视化周排班日历，灵活配置“长期出诊”与“临时出诊”状态。
3. **服务流程履约**：订单接收、就诊签到打卡、服务过程记录、服务完结核销。
4. **资产与收益结算**：个人账户中心、可提取金额、待结算金额、历史流水统计、提现申请与进度跟踪。
5. **专属获客二维码**：一键生成陪诊师个人小程序推广码，方便线下拓展客户。

### 2.3 培训考证体系
1. **考证题库**：内置陪诊专业理论考题，支持在线答题、即时判定、解析展示。
2. **错题集管理**：自动归纳错题，针对性复习巩固。
3. **认证报名**：支持在线报名考证并支付考培报名费。
